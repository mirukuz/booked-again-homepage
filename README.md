# booked-again-homepage

Static website for [BookedAgain](https://bookedagain.com) — support page and privacy policy.

Built with [Astro](https://astro.build) v6, deployed as a zero-JS static site.

## Pages

- `/` — Support page (Contact Us, Account Deletion, Privacy Policy link)
- `/privacy` — Privacy Policy

## Development

```bash
npm install
npm run dev       # start dev server at localhost:4321
npm run build     # build to dist/
npm run preview   # preview the build locally
```

## Testing

```bash
npm test          # run Vitest tests against built output
```
